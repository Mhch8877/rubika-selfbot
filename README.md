# 🤖 Rubika Self-Bot (ربات سِلف روبیکا)

یک اسکریپت سبک، سریع و خودکار برای مدیریت اکانت روبیکا و ارسال پیام‌های زمان‌بندی‌شده (مانند حضور و غیاب مدارس یا پیام‌های دوره‌ای) با پنل کنترل تعاملی ترمینال و پشتیبانی چندپلتفرمه.

## ✨ قابلیت‌های کلیدی (Features)

- ⏰ **ارسال زمان‌بندی‌شده دقیق:** ارسال پیام رأس ثانیه و دقیقه مشخص بدون کوچک‌ترین تأخیر.
- ⚡ **پیام فوری (Instant Message):** با وارد کردن علامت `..` در بخش زمان، پیام بدون معطلی و در همان لحظه شلیک می‌شود!
- 🔍 **جستجوی هوشمند گروه‌ها:** اسکن دیالوگ‌های کاربر، نمایش شماره‌گذاری‌شده گروه‌های هم‌نام و انتخاب آسان با یک عدد.
- 🎛️ **پنل کنترل تعاملی در ترمینال:** ویرایش آسان متن پیام، ساعت ارسال و گروه هدف بدون دست زدن به کد.
- 🔐 **پشتیبانی کامل از احراز هویت و رمز دومرحله‌ای (2FA):** تبادل کلیدهای نامتقارن RSA و ثبت پایدار سشن.
- 🔤 **اصلاح هوشمند چینش فارسی در کنسول (BiDi Fix):** جلوگیری از برعکس شدن حروف و کلمات فارسی در ترمینال ویندوز.
- 🌐 **چندپلتفرمه (Multi-Platform):** سازگار با ویندوز ۱۱، لینوکس (Arch, Ubuntu, Debian) و اندروید (Termux).

## 🚀 نحوه نصب و راه‌اندازی (Quick Start)

### ۱. اجرا در ویندوز ۱۱ (Windows)
1. مطمئن شوید [Python 3.9+](https://www.python.org/downloads/) نصب است و تیک **Add Python to PATH** را زده‌اید.
2. کافی است روی فایل **`start.bat`** دبل‌کلیک کنید. محیط مجازی به صورت خودکار ساخته شده، پیش‌نیازها نصب می‌شوند و برنامه اجرا خواهد شد.

### ۲. اجرا در لینوکس (Linux / Arch / Ubuntu)
```bash
git clone https://github.com/Mhch8877/rubika-selfbot.git
cd rubika-selfbot
chmod +x start.sh
./start.sh
```

### ۳. اجرا در گوشی با ترموکس (Android Termux)
```bash
pkg update && pkg install python git -y
git clone https://github.com/Mhch8877/rubika-selfbot.git
cd rubika-selfbot
pip install -r requirements.txt
python selfbot.py
```

## 🕒 فرمت‌های تنظیم زمان و تاریخ

هنگام انتخاب گزینه شماره `[2]` در منوی برنامه، می‌توانید از فرمت‌های زیر استفاده کنید:

| فرمت ورودی | مثال | رفتار برنامه |
| :--- | :--- | :--- |
| **تاریخ و ساعت مشخص** | `08:00/2026/09/27` | پیام در تاریخ و ساعت تعیین‌شده رأس ثانیه ارسال می‌شود. |
| **روتین روزانه** | `08:00` | پیام هر روز رأس ساعت ۸ صبح تکرار می‌شود. |
| **پیام فوری** | `..` | پیام بلافاصله در همان لحظه به گروه ارسال می‌شود! |
